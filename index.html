⚠ 需要 HTTP Server · Cần máy chủ HTTP

本遊戲必須透過 HTTP 伺服器執行；直接雙擊 .html 開啟時，瀏覽器會以 CORS 阻擋 JavaScript 模組與題庫 JSON 的讀取。

Trò chơi phải chạy qua máy chủ HTTP. Mở trực tiếp bằng tệp sẽ bị CORS chặn tải mô-đun và JSON.

請在專案根目錄執行 / Hãy chạy tại thư mục dự án:

python -m http.server 8000

然後開啟 / Sau đó mở: http://localhost:8000/
